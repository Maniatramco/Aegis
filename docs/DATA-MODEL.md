# Aegis data model

The current Oracle owner is **AGS_OWNER** with **12 custom application tables**.
The canonical table definitions, relationship diagrams, audit semantics, query
scripts and migration instructions now live under the project-root **DB/** folder.

See [the relational data model](../DB/docs/DATA-MODEL.md),
[database scripts and setup](../DB/README.md), and
[local migration verification](../DB/docs/VALIDATION.md).

The previous four-table AEGIS schema is retained as a migration snapshot. It is
not the schema used by the updated running application.
