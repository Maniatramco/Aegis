# Aegis data model

The current Oracle owner is **AGS_OWNER** with **12 custom application tables**.
The canonical table definitions, relationship diagrams, audit semantics, query
scripts and migration instructions now live under the project-root **ags_database/** folder.

See [the relational data model](../ags_database/ags_docs/DATA-MODEL.md),
[database scripts and setup](../ags_database/README.md), and
[local migration verification](../ags_database/ags_docs/VALIDATION.md).

The previous four-table AEGIS schema is retained as a migration snapshot. It is
not the schema used by the updated running application.
